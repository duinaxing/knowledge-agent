# 三分钟演示

前置条件：API/worker/Embedding 正常，60 份合成文档已 ready 并发布。真实完整评测在演示之外执行。

1. **0:00–0:35 登录与当前事实**：employee1 登录，问“PRJ-001 谁负责，现在是什么状态？”。展示项目来源及 updated_at，说明是登记信息。
2. **0:35–1:15 文档与追问**：追问“那验收标准呢？”。打开证据卡，查看原文和版本；当前登记来自业务表，验收来自文档。
3. **1:15–1:40 无答案**：问“去年盈利多少？”。解释资料没有记录时应明确未知，而不是补全数字。
4. **1:40–2:05 同名澄清**：employee2 登录，问“北辰项目是谁负责？”。其拥有两个同名候选权限，先选择项目编号。
5. **2:05–2:40 管理与失效**：管理员查看文档处理状态、发布/权限表单；在独立演示会话中调整访问范围，旧员工会话显示更新提示。演示后恢复合成权限，开启新会话。
6. **2:40–3:00 结果与限制**：展示工程测试、真实模型运行记录，明确区分本地联调、PostgreSQL 验收和人工语义评测，不宣称企业采用或工时收益。
