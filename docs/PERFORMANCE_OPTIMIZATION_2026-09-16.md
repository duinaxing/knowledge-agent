# 问答性能优化与复测（2026-09-16）

## 已实施

- 简单文档问答快路径：明确点名唯一有权访问的文档，且不是比较、历史、项目负责人/状态等复杂问题时，先检索再生成，省去模型规划。匹配目录仍经过原有 ACL；结果须命中指定文档，否则回到原 Agent 流程。
- 原有工具权限、知识 epoch、版本有效性、引用 ID 和最终答案校验保持生效。未授权文档不会因为快路径被访问；伪造引用测试仍被拒绝。
- 默认问答执行槽位由 4 改为 8；总期限保持 60 秒，模型/工具超时不变。未使用答案缓存、放宽超时或改变题目比例来提高成功率。
- 新配置 `SIMPLE_DOCUMENT_FAST_PATH=false` 可关闭快路径；`WORKER_CONCURRENCY=4` 可回退并发。
- 压测支持 `-Workers 8` 与 `-LegacyAgent`，每轮将配置写入 environment.json；默认压测仍用 4 槽位，优化复测必须显式指定 8。

## 复测结果

同一合成语料规模、100 个独立账号、70% RAG + 30% 通用问答、固定模型延迟 2 秒/调用，100 个请求在 0.032 秒内提交。对照是前一天的历史基线，两个优化一起启用，并非逐项独立实验。

| 指标 | 原 4 槽位 Agent | 快路径 + 8 槽位 |
|---|---:|---:|
| 最终有效回答 | 42/100 | 100/100 |
| 60 秒内有效回答 | 41/100 | 100/100 |
| 端到端 P95 | 61.484 秒 | 28.985 秒 |
| 排队 P95（已领取任务） | 60.953 秒 | 26.812 秒 |
| 提交成功率 | 100% | 100% |
| 提交接口 P95 | 0.906 秒 | 1.093 秒 |
| 短时读取 P95 | 0.609 秒 | 0.625 秒 |
| 峰值题库模型调用 | RAG 通常 3 次 | 所有 100 问均 1 次 |

本轮达到“100 人同时提问至少 95 人在 60 秒内有效回答”的目标。提交接口 P95 比 1 秒目标高约 93 毫秒，因此不是所有指标都达标。复杂、不点名文档的问题仍走多步 Agent，不能将此结果推广到所有问法。

本轮模型为模拟网关；没有真实 DeepSeek 消耗。旧基线总耗时包含少量引用/历史核对时间，新版将其独立记为 validation_seconds，比较时须保留这一口径差异。尚未完成长期持续压力、重复多轮峰值或真实模型复测，不能据此宣称生产企业级容量已验收。
